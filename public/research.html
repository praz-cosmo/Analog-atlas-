DATA PROVENANCE

What is live, and what is curated?

LIVE API

NASA archive search

Search results are requested from images-api.nasa.gov through the Express backend when a visitor submits a query. A short in-memory cache reduces repeated requests.

CURATED

Analog profiles

The 11 field profiles are editorial summaries based on NASA's Analog Explorer and Planetary Analogs pages. They do not refresh automatically and are not a complete global inventory.

SCHEMATIC

Site map

Earth pins are approximate regional markers drawn on an OpenStreetMap base. The Mars view is a schematic latitude/longitude plot, not a georeferenced basemap.

EDITORIAL RULES

How we avoid false claims.

  1. Use the source's own scope. A site is called NASA-documented only when it appears in NASA's cited analog resources.
  2. Name the shared process. A landscape is not an analog merely because it looks similar in a photograph.
  3. State the limits. Gravity, atmosphere, radiation, chemistry, scale and geological history may differ.
  4. Separate evidence from interpretation. A mineral resemblance does not prove past life; a terrain comparison does not prove identical geology.
  5. Keep links traceable. Each profile points to the NASA page that supports its inclusion. Open the original source before using a claim in formal work.
Important project status

ANALOG ATLAS is an independent student educational project. It is not built, operated, certified or endorsed by NASA. It currently connects to NASA's public image archive; it does not claim to receive live telemetry from spacecraft or to query every NASA planetary science dataset.
